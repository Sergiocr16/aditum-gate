Hikvision ANPR (lectura de placas)

La lista de placas autorizadas vive dentro de la cámara: ella reconoce la placa y abre el portón sola, sin depender de internet. Este equipo hace de puente en las dos direcciones — Aditum le manda los cambios de placas, y las lecturas se encolan acá y se reenvían a Aditum para la bitácora.

Base del API. Las lecturas se envían a , autenticadas con el token de este equipo (se asigna en la sección Seguridad).
En la cámara: Event → Alarm Setting → Alarm Server → Add. Destination = la IP de este equipo, URL = /anpr-event, Protocol = HTTP, Port = 80, ANR habilitado. No lleva token: el evento no sale de la red local. La dirección y las credenciales de la cámara no se configuran acá: se administran en Aditum (Acceso y ANPR) y llegan en cada envío de placas.
Apenas Aditum confirma una lectura, sale de la cola. Con 0 se borra en el acto; con más días queda como evidencia para revisar. Lo pendiente no se borra nunca: se reintenta hasta que Aditum lo confirme.

Habla directo con la cámara desde este equipo, sin pasar por Aditum: sirve para validar la instalación. Las credenciales se usan solo para la prueba, no se guardan (en operación normal llegan desde Aditum en cada envío).

«Probar conexión» solo lee la lista de la cámara y no cambia nada. «Agregar»/«Quitar» sí la modifican: usá una placa de prueba y acordate de quitarla al terminar.

Respaldo de configuración

Exportá la configuración de este equipo como archivo, o importá la de otro para clonarla. Al importar, la configuración se valida, se aplica de inmediato y el servicio se reinicia. El deviceId y la revisión de este equipo se conservan.

Provisionar token

Este equipo aún no tiene token: el backend de Aditum no puede administrarlo. Asigná uno (16–256 caracteres, sin espacios).

Token del dispositivo

Este equipo tiene token provisionado: es la credencial con la que el backend de Aditum lo administra.

Cambiar usuario / contraseña

Cambia las credenciales del login de este editor (no afecta el token del dispositivo).

Quitar el token del dispositivo

El backend de Aditum dejará de poder administrar este equipo (portones, config, tarjetas) hasta que se provisione un token nuevo. El equipo queda esperando token (provisión abierta): asigná uno de inmediato.

Reiniciar servicio

Se reinicia el proceso del equipo (aditum-device). Los portones y lectores quedan fuera de servicio unos 5–15 segundos mientras vuelve.
